# NurseGrid Courses — catalogue roadmap

Courses follow the hospital learning-centre pattern: enrol → learning activities in
order → post-test (25 questions, 80 % pass, 3 attempts per 24 h) → evaluation →
certificate + transcript entry. Lesson 1.1 of every course is free; the rest is Premium.
Every lesson is original NurseGrid content written for Ghanaian nursing and midwifery
students, uses diagrams that already exist in `public/diagrams/`, and ends with
practice questions matched from the question bank by `lesson.quiz.keywords`
(target ≥ 25 matching questions per lesson; checked before each course ships).

Each course is authored under `src/content/courses/<course>/` (one file per module,
`index.ts` for the course object) and registered in `src/content/courses/index.ts`.
A full-text review copy (`<course-slug>-review.html`) is generated with
`npx tsx src/content/courses/export-review.ts <course-slug>` for proof-reading before a
course is published.

## Per-course definition of done

1. Modules written in the house style (6–8 blocks per lesson; objectives, key points, exam callout).
2. Every diagram path exists in `public/diagrams/` and is git-tracked.
3. Keyword check run: each lesson ≥ 25 matching questions, no over-broad keywords.
4. `npm run typecheck` and `npx eslint src/content/courses` clean.
5. Review HTML generated and read by the course owner before the course is published.
6. Course added to `COURSES` in `src/content/courses/index.ts` (catalogue order = table order above).
